═══════════════════════════════════════════════════════════════════════════════
                         RELACIONES ENTRE CLASES
═══════════════════════════════════════════════════════════════════════════════

COMPOSICIÓN (1:1):
  User ──┐
         ├──► UserPreferences  (Un usuario TIENE UNA preferencia)

AGREGACIÓN (1:N):
  User ──┐
         ├──► Book (Un usuario TIENE MUCHOS libros)

ASOCIACIÓN (N:1):
  Book ──┐
         ├──► User (Muchos libros PERTENECEN A un usuario)

DEPENDENCIA:
  AuthRouter ───► User (AuthRouter USA el modelo User)
  BooksRouter ───► Book (BooksRouter USA el modelo Book)
  BooksRouter ───► User (BooksRouter REFERENCIA al modelo User)

COMPOSICIÓN:
  App ───► AuthRouter (App CONTIENE AuthRouter)
  App ───► BooksRouter (App CONTIENE BooksRouter)

DEPENDENCIA:
  App ───► Database (App SE CONECTA A Database)

═══════════════════════════════════════════════════════════════════════════════
                         ENDPOINTS Y MÉTODOS
═══════════════════════════════════════════════════════════════════════════════

AUTENTICACIÓN (/api/auth):
  POST   /api/auth/login          → login()          → Busca usuario por email
  POST   /api/auth/register       → register()       → Crea nuevo usuario
  GET    /api/auth/user/:id       → getUserById()    → Obtiene usuario por ID

LIBROS (/api/books):
  POST   /api/books               → createBook()     → Crea nuevo libro
  GET    /api/books/user/:userId  → getUserBooks()   → Obtiene libros del usuario
  GET    /api/books/:id           → getBookById()    → Obtiene libro por ID
  PUT    /api/books/:id           → updateBook()     → Actualiza libro
  DELETE /api/books/:id           → deleteBook()     → Elimina libro
